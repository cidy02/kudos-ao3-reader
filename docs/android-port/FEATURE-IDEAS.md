# Feature ideas for the owner (inspired by Apple's apps)

Ideas for Kudos **as a whole** (any platform, not only the iPhone Duo) that came from looking at how Apple's
own apps work during the Duo redesign (owner, 2026-10-24: *"if any apple apps give you inspiration for a
feature that you think should be in the app as a whole (meaning on any platform), do note it in a separate
file so i can review and approve or deny"*).

Nothing here is built until the owner approves it. Duo-only layout changes are not listed here: those are
Claude's decisions (owner, 2026-10-24 11:50) and are recorded in `DECISIONS.md`.

**How to answer:** change an idea's **Status** to `Approved` or `Denied` (a note is welcome), or just tell
Claude which numbers. Approved ideas join the Living Prompt's queue.

Each idea: what Kudos would do; the Apple app and behaviour it comes from; which platforms; why it helps a
reader; what it would cost (rough size, risks, AO3 traffic if any); and whether it changes stored data.
