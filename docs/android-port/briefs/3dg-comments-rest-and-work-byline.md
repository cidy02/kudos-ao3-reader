# 3dg: the rest of Comments, and an AO3 work's page (Android)

Done 2026-10-12 by Claude, alone. Gate 2,635. Pictures: `shots/3dg/`.

## Comments: compared and the same

- **Replying**: "Reply to <name>", the comment being answered quoted over the field,
  "Write your reply…", the count and the formatting row.
- **Hiding a thread's replies**: "Hide" becomes "Show 2".
- **A comment's menu**: Reply, Copy Link, Thread.
- **Browse Comments by Chapter**: All Comments with its total, the chapters, the note
  that AO3 gives no totals per chapter.

Left: Android's composer opens taller than iOS's. Not checked: editing and deleting one's
own comment (writes), a chapter's comments opened from the reader, the Inbox's rows.

## An AO3 work's page: one difference, fixed

The page is the same on both (identity, the four tiles, Read, the summary, On AO3's
chips, the tags, the figures, Comments) but for the byline: **a name that opens its
author was grey on Android**, like "Anonymous", which opens nothing. iOS draws it in the
page's accent (`AO3AuthorBylineView.tinted`). Android does now. Seen in Sepia, Dark and
Light; a name tapped opens its author.
