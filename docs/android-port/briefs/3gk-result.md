### 4. Complete custom-back source audit

All locations below are relative to `android/app/src/main/java/io/github/cidy02/kudos/`. “Unchanged” means no callback-API migration is needed by source inspection; device execution remains Claude's verification. The inventory found **30 `BackHandler` call sites across 27 files**. Activity Compose **1.12.0**, Navigation Compose **2.9.5**, and Material sheets/dialogs already use the supported AndroidX/platform callback machinery. No app `PredictiveBackHandler`, raw `OnBackInvokedCallback`, Activity `onBackPressed` override, or `KEYCODE_BACK` interception was found. `CommentsScreen.kt:3` imports `BackHandler` but never calls it.

Completion order: the focused IME/dialog/sheet handles its own Back first; inside the activity, the active leaf's enabled AndroidX handler takes priority over the containing navigation destination. Disabled selection handlers yield to navigation. Cancellation never invokes a `BackHandler` completion. The shell button is an explicit click, not a platform gesture: it uses the currently published screen callback first, then the AndroidX dispatcher, then the no-dispatcher navigation fallback. These are source conclusions, not emulator observations.
