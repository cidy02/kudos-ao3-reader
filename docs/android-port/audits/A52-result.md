# A52 — iOS backup, restore and sync guarantees against Android code

Read-only source audit, 2026-10-15. **Android keeps many of the supposedly uncovered rules, but does not keep all of them.** The most consequential gaps are a failed restore leaving database changes committed, export producing an archive its own reader rejects, and ignoring a stored AO3 ID when a URL is absent. Reading-log remapping once a book is matched, detached history, unsigned-tombstone rejection, and sweep-before-annotation-dedupe are implemented correctly.

## Missing rules worth fixing first

## Triage (Claude, 2026-10-15)

Each of the eleven was checked against the code before acting.

1. **Failed-restore rollback: real.** Rows commit, then files one transaction each; a late
   write failure ends a Replace part-applied. Not lost for good: a Replace first writes a
   safety copy (`BackupScreen.runImport`, `CREATE_NEW`), but the failure message never named
   it. 3ez: the message now says the library may be part replaced and names the copy. The
   rollback itself: brief **3fa** (Codex).
2. **Export limits: real.** Fixed in 3ez: the exporter refuses an archive over the
   importer's 1 GiB, a font over 4 MB, fonts over 32 MB together and a manifest over 8 MB.
3. **Stored AO3 ID: real.** Fixed in 3ez: `WorkIdentitySnapshot.index` takes
   `ao3WorkID ?: id-from-URL`, as iOS (and as the object's own doc already said).
4. **Repeated deletions: by design.** Android keeps every deletion's identity (brief 5c F6:
   an unsigned row id alone cannot remove a local deletion's AO3/URL suppressor). It errs
   toward keeping a deletion; no live record is lost. Recorded, not changed.
5. **Queue clock clamp: by design.** Content clocks are clamped to the archive's
   `exportedAt` against forged clocks; the iOS fixtures give an export date older than their
   own edits, which a real export cannot. Recorded, not changed.
6. **Blank locator: real.** Fixed in 3ez: the mapper already called a blank locator "not
   written" but assigned it with `?:`, which only guards null.
7. **First moved callback / trailing debounce: not a fault as shown.** Conditional on
   Readium's callback order; the debounce saves on quiet, on close and on flush.
8. **Incomplete export: real.** Brief **3fa** (Codex): name the books left out.
9. **Ambiguous font files, 10. conflict totals, 11. trust-key display:** no data lost (the
   existing bytes survive; explanations and a display only). Recorded, not changed.
