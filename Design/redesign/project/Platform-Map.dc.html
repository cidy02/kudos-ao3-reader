Native mapping

These boards are drawings, not code. Every element is a stock SwiftUI control on iOS 26 and later, where the system draws Liquid Glass, and has a Material 3 counterpart in Jetpack Compose. Apple sets behaviour and hierarchy; Android expresses the same meaning in its own idiom.

Glass is for navigation

Tab bar, toolbars, the bottom accessory and the reader's floating controls. Content (cards, rows, pages) stays on plain grouped surfaces. On Android those layers are tonal surfaces, not blur.

No custom chrome

Where the system has a control, use it as is. The only custom views are content: generated covers, the Symbols block, the work row and the reader page.

Sizes come from the system

Text uses Dynamic Type styles and M3 type roles, so it scales with the reader's settings. Targets stay at least 44 pt on iOS and 48 dp on Android.
