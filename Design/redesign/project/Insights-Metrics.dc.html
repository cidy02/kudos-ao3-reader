Reading Insights: what each card counts

One rule per card, so the code, the tests and How Reading Insights Are Counted all say the same thing. Shared rules: a period is the dates on screen; sittings under 15 seconds never count; rereads count unless the option is off; Read Aloud counts as time, never as pace; excluded fandoms, tags and works are left out of everything; a card with too little data is hidden, never shown as zero.
