Reading Insights: what each card counts

One rule per card, so the code, the tests and How Reading Insights Are Counted all say the same thing. Shared rules: a period is the dates on screen; sittings under 15 seconds never count; rereads count unless the option is off; Read Aloud counts as time, never as pace; excluded fandoms, tags and works are left out of everything; a card with too little data is hidden, never shown as zero. Added in review, 13 Nov 2026: a day runs 4:00 to 4:00 in the time zone the sitting was read in; visits to the same work under 5 minutes apart are one sitting; a period is compared with the same number of days of the one before; a finished period’s numbers never change afterwards; the last table lists the totals that must agree.
