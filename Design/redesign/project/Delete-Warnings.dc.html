Deleting a work Kudos can’t fetch again

A normal delete asks nothing. A work that is gone from AO3, or came from somewhere else, says so first.

When the warning shows

No longer on AO3. The last check found the work deleted, hidden or locked to someone else. Kudos already records this when it refreshes a work’s tags.

Imported from somewhere else. A PDF, EPUB, HTML or Word file from FanFiction.net, Wattpad, another site or your own files. The message names the format and the site when Kudos knows them.

Where it appears. Delete from Library (the work goes to Recently Deleted) and Delete Permanently, including after Select All. Deleting several at once counts them: “2 of these 5 can’t be downloaded again.”

Save the Original File… appears when Kudos still holds the file you imported, so it can go to Files first.

In Recently Deleted every row shows days left (red in the last week) and the same reason in an orange note.

A work still on AO3 deletes without a question, as today; Undo appears for a few seconds.
